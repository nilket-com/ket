# ADR 293 — tpch.q07 reachability

## Status
Proposed.

## Context

The reach cut in the 2-correctness : 1-reach cadence (q12 + q02 were the catchups) — "press the frontier
prudently." Board: 11 reach (q01-06, q10, q12, q14, q17, q20), 8 correctness. q07 is the prudent frontier press:
a **single, non-correlated** query whose one unproven high-value capability is the **`nation` self-join via SQL
aliases**.

```sql
SELECT supp_nation, cust_nation, l_year, SUM(volume) AS revenue
FROM (
  SELECT n1.n_name AS supp_nation, n2.n_name AS cust_nation,
         EXTRACT(year FROM l_shipdate) AS l_year, l_extendedprice * (1 - l_discount) AS volume
  FROM supplier, lineitem, orders, customer, nation n1, nation n2
  WHERE s_suppkey = l_suppkey AND o_orderkey = l_orderkey AND c_custkey = o_custkey
    AND s_nationkey = n1.n_nationkey AND c_nationkey = n2.n_nationkey
    AND ((n1.n_name = 'FRANCE' AND n2.n_name = 'GERMANY') OR (n1.n_name = 'GERMANY' AND n2.n_name = 'FRANCE'))
    AND l_shipdate BETWEEN DATE '1995-01-01' AND DATE '1996-12-31'
) AS shipping
GROUP BY supp_nation, cust_nation, l_year ORDER BY supp_nation, cust_nation, l_year
```

Most components are landed individually: comma-join recognition + n-ary execution (q03/q05/q10/q14/q20), derived
table over an all-inner chain, `EXTRACT(year FROM Date32)` (planner/binder/executor), `l_extendedprice*(1-l_discount)`
(q05 revenue), `BETWEEN` + OR residual predicates. The **unproven** capability is **one physical table scanned
twice under different aliases** (`nation n1, nation n2`) — a prerequisite shape for q08/q21 nation-role queries.

## Decision

Add q07 to the reachability harness in dev + strict modes, official Q7 text with parameters inlined
(`:1`→`'FRANCE'`, `:2`→`'GERMANY'`), official literal date bounds, **no LIMIT**, same SQL both modes (only
`lineitem` Decimal-vs-Float fixture types differ). **Verify-first**: harness-only **unless** the measured first
wall is a real engine gap (then → ADR 294).

### D1 — fixtures (none new) + the one-nation invariant
q07's five tables and every referenced column already exist (q05's family) — **no new fixture columns**.
**Load-bearing invariant: register exactly ONE `nation` `HarnessTable`** and let the SQL aliases `n1`/`n2` create
the self-join. Do **not** load two physical tables (`nation_1`/`nation_2`) — that would bypass the exact surface
q07 is meant to test (two scans of one base relation under different aliases).

### D2 — wiring
`Q7_DEV_SQL` (above) / `STRICT_Q7_SQL = Q7_DEV_SQL`; `q07_tables(strict, sf)` over `supplier`, `lineitem`,
`orders`, `customer`, `nation` (nation **once**; reuse q05's per-table builders); `run_dev_q07` / `run_strict_q07`;
`status_rows` entry; `main.rs` routes `"q07"`; matrix row. `facts_for_batch` on each.

### Verify-first — measure, don't assume
Run q07 after wiring and record the **measured** row at the **default scale (`sf=0.01`)**:
- `pass@execute` both modes → reach **12**, and the join (incl. the self-join) **must be keyed** at default scale
  — a tiny-scale pass is not evidence (q14/q17 cartesian lessons). If the self-join is *not* keyed and a cartesian
  appears, record that honest measured row (or cap the scale as a usage constraint), **not** a hollow green.
- a block/fail → the **precise** measured phase + reason names **ADR 294** (most likely self-join alias
  recognition, possibly the derived outer grouping or the OR/extract predicate). **No broad classifier** — a
  generic error stays `fail(unrecognized)` rather than widening the allowlist; no query rewrite to dodge a wall.

## Boundaries
- Reachability only; no q07 correctness oracle; `correctness.jsonl` unchanged.
- `BETWEEN` bounds literalized (both date literals — no interval runtime kernel).
- No engine work in this cut; an engine wall becomes ADR 294 (scoped separately — likely self-join).
- No query rewrite (keep the derived table, self-join aliases, `EXTRACT`, OR nation-pair predicate).
- **No extra fixture columns; no duplicate physical `nation` table.**

## Acceptance
- `run --query q07 --mode dev` and `--mode strict` record `pass@execute` at `sf=0.01` (keyed), **or** a precise
  measured red naming ADR 294.
- `matrix` includes q07; existing reach + correctness rows unchanged.
- Documented in `crates/toron/plans/impl/0293_tpch_q07_results.md`.

## Forward arc
If green: reach → 12, and q07 is a correctness-catchup candidate (grouped `SUM(volume)` by supp/cust nation +
year). If the self-join walls: **ADR 294 = self-join alias recognition** — the highest-value remaining capability
(unblocks q07/q08/q21). Either outcome is a clean frontier result.

## Why toron-home / harness
A `toron-tpch` reachability addition (query + wiring; no new fixtures). No `crates/toron` engine change expected;
if the verify-first run finds a wall, the engine ADR 294 it names is scoped separately.

## Council provenance
3/3 on q07 (Gemini selected it for self-join + date extraction; Claude + Codex converged with the verify-first
caveat). The dual keeps that caveat load-bearing — q07 is a **measurement cut first, not a promised green cell**.
Codex's sharp invariant folded: **one physical `nation` table, aliases create the self-join**. q22 (SUBSTRING —
confirmed but deep) and q09 (likely-green coverage) were the surfaced alternatives; the room chose the self-join
probe.
