# ADR 297 — tpch.q08 reachability

## Status
Proposed.

## Context

The reach run after the q10+q20 correctness catchup. Board: 12 reach, 10 correctness. q08 directly rides the
recent wins: its `all_nations` derived subquery is a multi-source comma body (ADR 294) with a
`nation n1, nation n2` self-join (ADR 293) — q07's now-green shape — and the outer is a q14-style ratio
(ADR 271/283/286 Decimal CASE/multiply/divide + operand alignment). Every feature is landed, so this is a
likely-green reach with a load-bearing keyed check.

```sql
SELECT o_year, SUM(CASE WHEN nation = 'BRAZIL' THEN volume ELSE 0 END) / SUM(volume) AS mkt_share
FROM (
  SELECT EXTRACT(year FROM o_orderdate) AS o_year, l_extendedprice * (1 - l_discount) AS volume,
         n2.n_name AS nation
  FROM part, supplier, lineitem, orders, customer, nation n1, nation n2, region
  WHERE p_partkey = l_partkey AND s_suppkey = l_suppkey AND l_orderkey = o_orderkey AND o_custkey = c_custkey
    AND c_nationkey = n1.n_nationkey AND n1.n_regionkey = r_regionkey AND r_name = 'AMERICA'
    AND s_nationkey = n2.n_nationkey AND o_orderdate BETWEEN DATE '1995-01-01' AND DATE '1996-12-31'
    AND p_type = 'ECONOMY ANODIZED STEEL'
) AS all_nations
GROUP BY o_year ORDER BY o_year
```

## Decision

Add q08 dev+strict, tpchgen Q8 text with params inlined (`:1`→`'BRAZIL'`, `:2`→`'AMERICA'`,
`:3`→`'ECONOMY ANODIZED STEEL'`), `BETWEEN` bounds literal, **no LIMIT**, same SQL both modes
(`STRICT_Q8_SQL = Q8_DEV_SQL`). **Verify-first**: harness-only unless a measured wall appears (then → ADR 298).

### D1 — fixtures (none new): 8 logical factors, 7 physical tables
q08's derived body names **eight logical relation factors** but only **seven physical harness tables** —
`nation n1` and `nation n2` are SQL aliases over **one** registered `nation` fixture (the ADR 293 invariant; do
**not** add `nation_1`/`nation_2`). All seven tables + every referenced column already exist (q02/q05/q07
families): `part`(`p_partkey`,`p_type`), `supplier`(`s_suppkey`,`s_nationkey`),
`lineitem`(`l_partkey`,`l_suppkey`,`l_orderkey`,`l_extendedprice`,`l_discount`),
`orders`(`o_orderkey`,`o_custkey`,`o_orderdate`), `customer`(`c_custkey`,`c_nationkey`),
`nation`(`n_nationkey`,`n_name`,`n_regionkey`), `region`(`r_regionkey`,`r_name`). **No new fixture columns.**

### D2 — wiring
`Q8_DEV_SQL`/`STRICT_Q8_SQL = Q8_DEV_SQL`. **`q08_tables(strict, sf) = q05_tables + part`** — reuse the q05
physical family (`customer`, `orders`, `lineitem`, `nation`, `supplier`, `region`) plus `part`; **not** a bespoke
fixture stack, and **exactly one** `nation`. `run_dev_q08`/`run_strict_q08`; `status_rows` entry; `main.rs` routes
`"q08" | "q8"`; matrix row.

### Verify-first — measure, don't assume
Record the measured row at **sf=0.01**:
- `pass@execute` both modes → reach **13**, and the 8-factor join (incl. the self-join) **must be keyed** — a
  tiny-scale pass is not evidence (q14/q17 cartesian lesson; load-bearing for the biggest join yet). A cartesian
  is an **honest red**, not a green.
- a block/fail → the **precise** reason names ADR 298. **No broad classifier** (generic → `fail(unrecognized)`);
  no query rewrite.

## Boundaries
- Reachability only; **no q08 correctness oracle**; `correctness.jsonl` unchanged. `BETWEEN` literalized (no
  interval kernel). No engine work unless a wall is measured. **One physical `nation` table**; no new fixtures.
- **For the *future* q08 correctness (not this cut):** `p_type='ECONOMY ANODIZED STEEL'` + `r_name='AMERICA'` +
  1995-96 may be **empty at sf=0.01** — fine for *reach* (empty-but-executes = `pass@execute`), but the eventual
  correctness oracle must guard non-emptiness (the q17 masked-empty lesson). **The results doc must state
  explicitly whether q08's output is empty at sf=0.01.**

## Acceptance
- `q08 dev=pass@execute strict=pass@execute` at sf=0.01 (keyed), or a precise measured red naming ADR 298.
- `matrix` includes q08; existing reach + correctness rows unchanged. Documented in
  `crates/toron/plans/impl/297_tpch_q08_results.md` (including the empty-or-not fact).

## Forward arc
If green: reach → 13 (unchecked-green = q04, q07, q08). The next correctness catchup narrows the gap (q07 / q04 /
q08-if-non-empty). q09 (substring LIKE + 6-table) remains the other reach machete.

## Why toron-home / harness
A `toron-tpch` reachability addition (query + wiring; no new fixtures). No `crates/toron` engine change expected;
a measured wall scopes ADR 298 separately.
