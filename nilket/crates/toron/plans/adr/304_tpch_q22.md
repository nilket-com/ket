# ADR 304 — tpch.q22 reachability

## Status
Proposed.

## Context

Reach frontier reopens after the level board (14 reach / 14 correctness). q22 is the next machete because its
first wall is the **cleanest, single, broadly-useful** engine gap: SQL `SUBSTRING(x FROM s FOR n)` — a real
surface-area feature (string slicing), confirmed absent in frontend lowering. This is a **verify-first reach
probe**: add q22 unchanged, measure the first wall, classify it precisely, and let it name the engine ADR.

```sql
SELECT cntrycode, COUNT(*) AS numcust, SUM(c_acctbal) AS totacctbal
FROM (
  SELECT SUBSTRING(c_phone FROM 1 FOR 2) AS cntrycode, c_acctbal
  FROM customer
  WHERE SUBSTRING(c_phone FROM 1 FOR 2) IN ('13','31','23','29','30','18','17')
    AND c_acctbal > (SELECT AVG(c_acctbal) FROM customer
                     WHERE c_acctbal > 0.00 AND SUBSTRING(c_phone FROM 1 FOR 2) IN ('13','31','23','29','30','18','17'))
    AND NOT EXISTS (SELECT * FROM orders WHERE o_custkey = c_custkey)
) AS custsale
GROUP BY cntrycode ORDER BY cntrycode
```

q22 hits `SUBSTRING` in the derived SELECT **and** the `WHERE … IN`, so frontend lowering reaches it first —
before the correlated `NOT EXISTS` and the `AVG`-threshold subquery.

## Decision

Add q22 dev+strict, official-ish shape (`:1` country codes inlined), no LIMIT, `STRICT_Q22_SQL = Q22_DEV_SQL`.
**Verify-first** — harness-only; this cut **measures** the first wall, it does not solve it.

### D1 — fixtures (none new)
`q22_tables(strict, sf)` over `customer` + `orders` (the `NOT EXISTS` target). Every referenced column already
exists: `c_phone` (Utf8), `c_acctbal` (Decimal128(15,2)/Float64), `c_custkey`, `o_custkey`. **No new fixture
columns.**

### D2 — wiring
`Q22_DEV_SQL`/`STRICT_Q22_SQL`; `q22_tables`; `run_dev_q22`/`run_strict_q22`; `status_rows`; `main.rs` routes
`"q22"`; matrix row.

### Verify-first — measure + classify precisely
Run q22 at sf=0.01; record the measured row. Expected: **`blocked(unsupported_substring@plan)`** in both modes
(the `SUBSTRING` expression frontend lowering can't lower).
- **Classify it precisely** — add a specific `unsupported_substring` telemetry reason matching the SUBSTRING
  reject (the raw frontend error names `Substring`); do **not** leave it as
  `fail(unrecognized)` or fold it into a generic bucket. If the raw reject is *not* specific to SUBSTRING, that's
  a sub-finding (record the raw error; don't force a broad classifier).
- **Do not solve** the correlated `NOT EXISTS` or the `AVG`-threshold subquery in this cut — they sit *behind*
  SUBSTRING and are deferred (later ADRs name them once SUBSTRING lands).

## Boundaries
- Reachability only; no q22 correctness oracle. No engine work in this cut (SUBSTRING is ADR 305). No new fixtures.
- The classifier addition must be **specific** to SUBSTRING (no broad allowlisting).

## Acceptance
- `q22 dev` and `strict` record a **precise** measured row at sf=0.01 — expected
  `blocked(unsupported_substring@plan)` (or another precise wall, or the unlikely `pass@execute`). Reach +
  correctness rows unchanged (q22 stays red until SUBSTRING + the deferred features land).
- `matrix` includes q22; a harness test pins the measured row + the precise reason. Documented in
  `crates/toron/plans/impl/304_tpch_q22_results.md`.

## Forward arc
**ADR 305 = SUBSTRING expression support** — lower/bind `SUBSTRING(x FROM start FOR len)` + an Arrow string-slice
exec (a self-contained, broadly-useful string scalar). Once it lands, q22 re-measures its next wall (the correlated
`NOT EXISTS` and/or the `AVG`-threshold subquery → further ADRs). q13 (non-equi outer-join `ON` predicate) and
q19 (disjunctive predicate) remain the other reach machetes.

## Why toron-home / harness
A `toron-tpch` reachability addition (query + wiring + a precise classifier); no `crates/toron` engine change in
this cut. The SUBSTRING engine cut is ADR 305. No Wendelon / cross-ring surface.

## Council provenance

**classify SUBSTRING precisely** (not generic/unrecognized); **do not** mix in correlated `NOT EXISTS` /
`AVG`-threshold / join semantics — keep ADR 304 crisp; forward arc = **ADR 305 SUBSTRING**. q13 (non-equi
outer-join predicates) deferred as a deeper semantic cut.
