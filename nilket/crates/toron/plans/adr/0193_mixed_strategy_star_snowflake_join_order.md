# ADR 193: Mixed-Strategy Star/Snowflake Join Order

**Status:** Promoted. **Migration:** `plans/impl/0193_mixed_strategy_star_snowflake_join_order.md`.

ADR 177–192 climbed the **uniform-strategy** tree: all-hash and all-broadcast stars and snowflakes recognize, order, actuate, execute, and self-tune. The remaining gap is the realistic warehouse query — one **fat** dimension that wants `HashPartitioned` and several **small** ones that want `Broadcast` at the same local star level. Today that declines: the actuator collapses the per-edge strategies to one uniform summary and rejects the mixture as `MixedStrategyStar`. ADR 193 makes the baseline mixed root star/snowflake **actuate and execute**, closing the next tree-shaped rung without claiming arbitrary mixed-tree coverage.

## Grounding (the cost model is a red herring; the fragmenter reuse is proven; the binder gate is the cut)

Iter-0 proposed a "strategy-aware cost model" and the promoted draft proposed a heterogeneous-staging fragmenter. **Implementation falsified both.** The cost model was never needed, and — the load-bearing correction — the fragmenter cliff does not exist for the plan the binder actually emits. The cut is binder-only.

- **Per-edge strategy is already chosen.** `choose_auto_join_strategy` (`binder/join.rs:430`) picks hash vs broadcast per edge by the byte cap during each `bind_scoped_join` preflight. 193 invents no strategy selection.
- **Row-only ordering remains the preserved first invariant.** `order_cost` (`join_order.rs`) is `Σ(len-idx)·rows`; it ranks dimension selectivity regardless of each edge's final strategy. The `adr181_reorder_is_strategy_invariant` and new `adr193_reorder_cost_stays_row_only` guards pin that `rank_star_order` / `order_cost` / `classify_star_order_action` never read `JoinStrategy`. **193 preserves that invariant, it does not invert it.** It does not assert row-only ranking is the final global mixed-strategy cost model; that remains evidence-driven future work.
- **Mixed is order-variant, and the cost-optimal order is the fragmentable one.** This is the fact that collapses the fragmenter into the existing path. `choose_auto_join_strategy` only broadcasts a dimension when its probe is *scan-linear* (`right_viable = right_build_candidate.filter(|_| left_input.probe_scan_linear)`), so a hash join earlier in the order forces every later dimension to hash. The row-only cost optimum puts the **small (broadcast) dimensions first and the fat (hash) dimension last** — exactly `Join(Hash, probe=Join(Broadcast, …, scan))`, a clean left-deep **broadcast-first / hash-last** shape. That shape is precisely what `fragment_join_plan` already stages: the topmost hash join sees bare `Exchange(scan)` inputs after its broadcast-first probe subtree fragments through the existing broadcast path. The mixed star/snowflake the binder emits fragments and executes with **zero** fragmenter change.
- **The binder already builds and the executor already runs mixed plans.** When star actuation declined pre-193, `bind_plan_with_trace` fell back to recursive `bind_join`, and the in-process executor evaluated the nested mixed tree (`snowflake_order_evidence_is_observational`). 193 makes the *actuated* path emit the same fragmentable shape under a receipt.
- **The receipt could not tell the truth.** `StarOrderEvidence.strategy` was a single `Broadcast | HashPartitioned`. Acted receipts now carry a generic per-edge `edge_strategies` list plus an explicit `Mixed` summary — `strategy=mixed` without per-edge detail is not honest enough.

**The consequence sets the cut's shape:** the load-bearing safety property is **selected-preflight validity**, not a fragmenter capability. The selected physical order is authoritative; if its own preflight proves a valid mixed placement, the plan it emits is the broadcast-first/hash-last shape the existing fragmenter already handles, and end-to-end distributed execution proves it. The binder gate is the ADR; the fragmenter is reused, not extended.

## Decision

Make mixed hash/broadcast **root** local-star levels (flat stars and snowflake roots) actuatable and executable in the baseline shape, reusing the existing distributed fragmenter unchanged. Branch-local mixed stays deferred; shapes outside the root actuator's authorized domain remain on the observe-only evidence path.

**D1 — "Strategy-aware" means per-edge-aware, not strategy-costed.** 193 consumes the preflight `DecisionReceipt` vector instead of collapsing it to a uniform strategy. `order_cost`, `rank_star_order`, and soft-margin classification stay row-only — no `strategy_aware_order_cost`, no network-cost term, no cost-based strategy choice. If later verdicts show row-only mixed ordering misranks, that is a separate cost-model ADR.

**D2 — Explicit `Mixed` classification after the strict uniform recognizers.** `uniform_star_order_strategy` / `uniform_snowflake_order_strategy` remain the strict ADR-181/192 fast paths, unchanged. A new classifier runs after them: all-broadcast (valid placements) → `Broadcast`; all-hash → `HashPartitioned`; a valid hash/broadcast mixture → `Mixed`; invalid placement, missing decision, non-inner/non-equi, or an **unauthenticated** snowflake `Broadcast + Natural` → decline. ADR 192's `composite_build_positions` authentication still gates any `Broadcast + Natural`; mixed classification must not bypass that fence.

**D3 — Represent local strategy as a `Mixed` summary plus per-edge decisions.** Add `Mixed` to the strategy summary (extend `StarOrderStrategy` or an equivalent local summary), and carry the preflighted per-edge strategy/placement list on the acted receipt. A mixed receipt renders `strategy=mixed` with detail `strategies=[c:hash_partitioned/natural,s:broadcast/swapped_right_build]`. Render/telemetry only.

**D4 — Authorize `Mixed` at root local-star levels by selected-preflight validity (the safety gate).** The **selected** physical order is authoritative. A flat-star or snowflake-root level acts on `Mixed` when:
- the **selected** preflight classifies as `Mixed` — `uniform_star_order_strategy` / `uniform_snowflake_order_strategy` both returned `None` on a *valid* placement set, which by construction means at least one broadcast edge and one hash edge (a genuinely mixed receipt);
- that selected preflight proved **valid placements**, including the ADR 192 composite-build authentication of any `Broadcast + Natural` (an invalid placement returns `None` → decline before the mixed tier);
- **branch-local** mixed stays declined through the hash-only branch authorization (`HashOnlyCompositeProbe` requires uniform hash), keeping nested-broadcast-probe risk out of branch composites.

The per-dimension **fingerprint is no longer an authorization gate.** The cost-optimal reorder legitimately changes a dimension's strategy (a dim that was hash in the declared order becomes broadcast once it moves before the hash join), so a declared==selected fingerprint match would block exactly the reorder this ADR exists to enable. The fingerprint is retained for **receipt honesty** (per-edge detail) and is available for negative tests. This is the narrow form of "selected wins": the selected order is authoritative *because its own preflight proves a valid, fragmentable mixed plan*, not by fiat.

**D5 — Distributed execution is the honesty gate; the fragmenter is reused unchanged.** The headline runs a mixed star/snowflake through distributed execution and digest-matches an all-hash / declared-order baseline. Implementation proved the binder emits a broadcast-first/hash-last left-deep shape that the **existing** `fragment_join_plan` already stages — no fragmenter change, no new worklist, uniform hash and uniform broadcast fragmentation byte-identical (an architecture guard pins that `distributed/fragment.rs` never learns the `Mixed` variant). No fragmenter change is made unless a new discriminating execution fixture actually fails; none does. The arbitrary-bushy general case is deferred.

**D6 — `MixedStrategyStar` survives for still-deferred shapes; observed-only is their evidence path.** It remains the decline reason for branch-local mixed and invalid placements. Shapes outside the root actuator's authorized domain — a **non-scan-linear probe** (the fact table arrives via `LIMIT`/sort/aggregate, so no edge can broadcast and the actuator cannot guarantee a fragmentable left-deep plan), insufficient root children, and bushy/non-baseline trees — are **recognized observationally** (`ObservedSnowflake`) but not actuated. After 193, "observation" means recognized-but-not-actuatable; the observe-only path is pinned by non-scan-linear-probe fixtures.

**D7 — No topology expansion or optimizer shell.** No galaxy, bridge, many-to-many, cycles, outer joins, memo, Cascades, `Optimizer`, or broad `PlanProperties`. 193 consumes the existing flat-star and single-fact snowflake recognizer outputs.

**D8 — Ring/runtime boundaries.** Toron-owned, **binder-only**. No fragmenter, executor kernel, storage, Wendelon, PBC, SQL grammar, or wire change. An architecture guard pins that the `Mixed` vocabulary stays inside the binder and never reaches `distributed/fragment.rs`.

## Honesty gate

`mixed_strategy_star_actuates_and_executes_distributed`: the canonical mixed star (`orders ⋈ small` broadcast + `orders ⋈ big` hash, small under-cap → broadcast, big over-cap → hash) stops declining, emits a root `join_order` receipt with `strategy=mixed` and per-edge `strategies=[…]` detail carrying both a broadcast and a hash edge, executes distributed across multiple workers through the **existing** fragmenter, and digest-matches the all-hash baseline (built with `force_hash_join_ids`). It must **fail on pre-193** (declined, never actuated). Fragment-shape success ≠ correctness; lock by execution. The companion `mixed_strategy_snowflake_root_actuates_with_mixed_receipt` locks the reordering snowflake root (the case where the selected order genuinely differs from declared, so selected-preflight authority — not fingerprint match — is what authorizes it).

## Forward Arc

`192 broadcast-snowflake uniformity → 193 mixed-strategy star/snowflake order (this; binder-only, existing fragmenter reused) → galaxy evidence → bridge evidence → bounded topology actuation → memo when receipts show local decisions fighting`. 193 closes the root-level mixed tree rung; branch-local mixed and arbitrary bushy mixed trees remain explicit follow-ons. A heterogeneous-stage fragmenter (for shapes the broadcast-first/hash-last reorder cannot express) is deferred until a discriminating execution fixture forces it.

## Deferred (named)

Strategy-aware cost model; cost-based strategy choice; branch-local mixed actuation; arbitrary bushy mixed plans; galaxy/bridge topology; outer joins; memo/Cascades; durable/persisted optimizer evidence.
