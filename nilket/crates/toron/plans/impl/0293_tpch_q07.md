# ADR 293 — Implementation plan: tpch.q07 reachability

Pairs with `plans/adr/0293_tpch_q07.md`. Harness-only (`toron-tpch`) expected; no `crates/toron` engine change
unless the verify-first run measures a real wall (then → ADR 294). Anchors are current-tree.

## Phase 0 — verify-first probe (the self-join is the question)
Wire the minimum and **measure the real first wall** before declaring anything:
```
scripts/cargo-cgroup run -p toron-tpch -- run --query q07 --mode dev --sf 0.01 --allow-blocked
scripts/cargo-cgroup run -p toron-tpch -- run --query q07 --mode strict --sf 0.01 --allow-blocked
```
Headline probe: does the binder resolve **`nation n1, nation n2`** (two scans of one base relation under
different aliases) with qualified `n1.n_name`/`n2.n_name`? Outcomes:
- `pass@execute` → reach 12 (self-join works);
- block/fail on the self-join → record the precise reason verbatim → names **ADR 294 = self-join alias
  recognition**;
- a different wall (disjunctive nation-pair `OR`, derived outer grouping, `EXTRACT` projection) → record it
  precisely.
No broad classifier; a generic error stays `fail(unrecognized)`. No query rewrite. Don't leave probe code behind.

## D1 — fixtures: none new + the one-nation invariant
All five q07 tables/columns already exist (q05's family). Do **not** add columns. **Register exactly ONE `nation`
`HarnessTable`**; the SQL aliases `n1`/`n2` create the self-join. Do **not** create `nation_1`/`nation_2` physical
tables — that bypasses the surface q07 tests.

## D2 — wiring — `lib.rs` + `main.rs`
- `Q7_DEV_SQL` (official shape, `:1`→`'FRANCE'`, `:2`→`'GERMANY'`, both `BETWEEN` bounds literal dates, no LIMIT);
  `STRICT_Q7_SQL = Q7_DEV_SQL`.
- `fn q07_tables(strict: bool, scale_factor: f64) -> Vec<HarnessTable>` over `supplier`, `lineitem`, `orders`,
  `customer`, `nation` (nation **once**; reuse the existing per-table builders / mirror `q05_tables`);
  `facts_for_batch` on each.
- `run_dev_q07` / `run_strict_q07` via `run_query_with_tables("q07", …, q07_tables(strict, sf))`.
- `status_rows()` — add `"q07"` to the implemented list; matrix row renders.
- `main.rs` — route `"q07"` in `run_command` (dev/strict).

## Tests — `crates/toron-tpch/tests/harness.rs`
- `q07_executes_in_both_modes` (or the precise measured-wall assertion if it doesn't reach execute): dev+strict at
  `sf=0.01`, `Status::Pass` / `Phase::Execute` with a digest. Explicit-64MB-stack thread (q07 is deep:
  6-relation join incl. self-join + derived table + grouped aggregate).
- **Keyed-at-default-scale evidence** — q07 must be keyed at `sf=0.01` (multi-table incl. self-join; q14/q17
  cartesian lesson). A `q07_runs_keyed_at_default_scale`-style check if feasible; a cartesian is an honest red,
  not a green.
- **No-regression** — existing reach (q01-06/10/12/14/17/20) + correctness cells stay green (full `-p toron-tpch`
  suite). No fixture change, so the wiring must not disturb anything.
- If q07 walls, assert the **precise** measured phase/reason (not a green); the results doc names ADR 294.

## Seal gate (via `scripts/cargo-cgroup`, after `fmt`)
```
scripts/cargo-cgroup fmt
scripts/cargo-cgroup fmt -- --check
scripts/cargo-cgroup check -p toron-tpch --all-targets
scripts/cargo-cgroup test -p toron-tpch
scripts/cargo-cgroup run -p toron-tpch -- run --query q07 --mode dev --sf 0.01 --allow-blocked
scripts/cargo-cgroup run -p toron-tpch -- run --query q07 --mode strict --sf 0.01 --allow-blocked
scripts/cargo-cgroup run -p toron-tpch -- matrix
scripts/cargo-cgroup run -p toron-tpch -- correctness-matrix
git diff --check
```
The two live q07 runs are part of the gate — they produce the measured row (green or recognized blocked). If the
measured row is an honest `fail(unrecognized)`, do not invent a blocker just to make the live command exit green;
pin that result in the harness test/results doc and keep the rest of the gate green.

## Results doc
`crates/toron/plans/impl/0293_tpch_q07_results.md`: the measured q07 dev+strict rows at `sf=0.01`
(keyed-comma-join + **self-join** confirmation if green); whether the self-join bound; if a wall, the precise
phase/reason naming ADR 294; confirmation existing reach + correctness rows unchanged.

## Risk / blast radius
- Harness-only (expected). No fixture change → low blast radius; the full `-p toron-tpch` suite + the two matrices
  are the net.
- **The self-join is the probe** — if it walls, honest red + name ADR 294 (self-join unblocks q07/q08/q21); do not
  smuggle engine work into this reach cut.
- **One physical `nation` table** — a `nation_1`/`nation_2` shortcut would fake-pass without testing the self-join.
- **Verify at default scale** — a tiny-scale-only pass (or a cartesian) over a self-join is not evidence.
