# ADR 297 — Implementation plan: tpch.q08 reachability

Pairs with `plans/adr/297_tpch_q08.md`. Harness-only (`toron-tpch`) expected; no `crates/toron` engine change
unless the verify-first run measures a real wall (then → ADR 298). Anchors are current-tree.

## Phase 0 — verify-first probe (likely green; the keyed check decides)
Wire the minimum and **measure the real row** before declaring anything:
```
scripts/cargo-cgroup run -p toron-tpch -- run --query q08 --mode dev --sf 0.01 --allow-blocked
scripts/cargo-cgroup run -p toron-tpch -- run --query q08 --mode strict --sf 0.01 --allow-blocked
```
Expected `pass@execute` (all features landed: derived multi-source body + self-join [293/294], `EXTRACT`, ratio
division [286/283], CASE-in-SUM [q14]). If it blocks/fails, record the precise reason verbatim → ADR 298. No broad
classifier; no query rewrite; no probe code left behind. **Also record whether the output is empty at sf=0.01**
(for the future q08 correctness oracle).

## D1 — fixtures: none new + one-nation invariant
All 7 q08 tables/columns exist. Do **not** add columns. **Register `nation` exactly once**; the SQL's
`nation n1`/`nation n2` are aliases over that single fixture (8 logical factors, 7 physical tables — the ADR 293
rule). No `nation_1`/`nation_2`.

## D2 — wiring — `lib.rs` + `main.rs`
- `Q8_DEV_SQL` (tpchgen Q8, `:1`→`'BRAZIL'`, `:2`→`'AMERICA'`, `:3`→`'ECONOMY ANODIZED STEEL'`, `BETWEEN` literal
  date bounds, no LIMIT); `STRICT_Q8_SQL = Q8_DEV_SQL`.
- **`fn q08_tables(strict, sf) = q05_tables(strict, sf) + part`** — extend the q05 family with `part` (reuse
  `q05_tables` and the existing `part` builder); do **not** hand-roll a bespoke 7-table stack; `nation` stays
  **once**; `facts_for_batch` on each.
- `run_dev_q08` / `run_strict_q08` via `run_query_with_tables("q08", …, q08_tables(strict, sf))`.
- `status_rows()` — add `"q08"` to the implemented list; matrix row renders.
- `main.rs` — route `"q08" | "q8"` in `run_command` (dev/strict).

## Tests — `crates/toron-tpch/tests/harness.rs`
- `q08_executes_in_both_modes` (or the precise measured-wall assertion if it doesn't reach execute): dev+strict at
  `sf=0.01`, `Status::Pass` / `Phase::Execute` with a digest. Explicit-64MB-stack thread (q08 is the deepest yet:
  8-factor join incl. self-join + derived table + outer grouped ratio).
- **Keyed-at-default-scale evidence** — q08 must be keyed at `sf=0.01` (8-factor join; the q14/q17 cartesian
  lesson — load-bearing). A `q08_runs_keyed_at_default_scale`-style check if feasible; a cartesian is an honest
  red, not a green.
- **No-regression** — existing reach (q01-07/10/12/14/17/20) + correctness cells stay green (full `-p toron-tpch`);
  no fixture change, so the wiring must not disturb anything.
- If q08 walls, assert the **precise** measured phase/reason (not a green); the results doc names ADR 298.

## Results doc

reach + correctness rows unchanged.

## Risk / blast radius
- Harness-only (expected). No fixture change → low blast radius; the full `-p toron-tpch` suite + the two matrices
  are the net.
- **Verify at default scale** — a tiny-scale-only pass (or a cartesian) over the 8-factor join is not evidence
  (q14/q17 lesson). Confirm keyed at sf=0.01.
- **One physical `nation` table** (`q08_tables = q05_tables + part`) — a `nation_1`/`nation_2` shortcut would
  fake-pass without testing the self-join.
- If q08 walls, honest red + name ADR 298; no broad classifier, no rewrite, no smuggled engine work.
